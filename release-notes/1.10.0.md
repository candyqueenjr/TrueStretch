## TrueStretch 1.10.0 — Vignette and Improve Clarity are now read from your account

### What's new
- **Two more in-game settings are read for real.** In Optimize Max, the "Inside VALORANT" rows for **Vignette** and **Improve Clarity** used to say "Set in game" because TrueStretch didn't know where VALORANT keeps them. Now it reads both from the same account settings file as the other rows (the local copy VALORANT keeps of your Riot account settings), so each row shows your real value: Off is marked as done, On tells you to switch it off in VALORANT → Settings → Video → Graphics Quality.
- Vignette darkens the edges of the screen, which hides detail where enemies peek from. Improve Clarity is a sharpening filter that costs a little FPS.

### Why it matters for the player
Every row in "Inside VALORANT" now reads your actual setting. No more guessing or checking the game's menu for a row that was already fine.

### Details
- Read-only, like the other in-game rows: these settings live in your Riot account, so only the game can change them. TrueStretch never writes that file.
- If you have never touched a setting, VALORANT doesn't store it and the row says "Game default" with the value to pick.
- Also checked for this release: VALORANT 13.10. Every game-log line TrueStretch relies on still looks the same.
