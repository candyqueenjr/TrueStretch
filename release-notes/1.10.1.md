## TrueStretch 1.10.1 — Old versions no longer pile up on your drive

### What's fixed
- **Leftover files from every old version are now removed.** When you start TrueStretch.exe, it unpacks itself once into a folder named after its version (inside your user's Local AppData, where Windows Defender is happy with it). After an update, the old version's folder was supposed to be deleted — but a path mix-up meant it never was. Every version you have ever run stayed on the drive, about 80 MB each. If you have updated daily since 1.1.1, that was close to a gigabyte of dead weight.
- Starting with this version, TrueStretch deletes the other versions' folders at every start and keeps only the one it runs from. The very first start of 1.10.1 cleans up everything older in one go.

### Why it matters for the player
Nothing changes in how the app looks or works — you simply get your drive space back, and it stays that way after every future update.

### Details
- A folder is never touched while a copy of TrueStretch is still running from it (for example the old version that is still closing during an update). It is removed at the next start instead.
- Only version-numbered folders inside TrueStretch's own unpack location are affected; settings, backups and logs live elsewhere and are untouched.
- Also checked for this release: VALORANT 13.10. Every game-log line TrueStretch relies on still looks the same.
