## TrueStretch 1.2.0 — No more Sticky Keys pop-ups, and your real in-game settings

### What's new
- **Optimize Max now checks the three Windows keyboard-shortcut pop-ups:** Sticky Keys (press Shift 5 times), Filter Keys (hold the right Shift key for 8 seconds) and Toggle Keys (hold Num Lock for 5 seconds). Windows turns these shortcuts on by default, and all three are things you do while walking, crouching or holding an angle. The pop-up appears over VALORANT and steals focus, and Filter Keys makes Windows ignore quick key presses.
- Apply turns off **only the shortcut**, never the feature itself. Sticky, Filter and Toggle Keys stay available in Windows Settings > Accessibility > Keyboard if you ever want them.
- If you actually use one of these features (it's switched on), TrueStretch leaves it and its shortcut alone and just shows it as information.
- **The "Inside VALORANT" list now shows your real settings.** NVIDIA Reflex, Multithreaded Rendering, Material/Texture/Detail/UI quality, Anti-Aliasing, Anisotropic Filtering, Bloom, Distortion, Cast Shadows and the FPS limit are read from VALORANT's own settings file for the account you played last. Each one says what it is now, what to pick and the exact menu (for example "Multithreaded Rendering: Off → On", or "60 FPS cap — your screen is 144 Hz"). These live in your Riot account, so TrueStretch only reads them; you change them in the game.

### Why it matters for the player
No more "Do you want to turn on Sticky Keys?" window in the middle of a round, and no more missed key presses after holding Shift. The change is applied live and also kept for the next time you sign in to Windows. And if Multithreaded Rendering got switched off or an FPS cap is holding you below your monitor's refresh rate, Optimize Max now tells you instead of guessing.

### Details
- Like every Optimize Max item, each change is verified after it is made, and Undo puts back the exact original value (the live Windows setting and the registry copy).

### What's fixed
- When TrueStretch pins VALORANT to the high-performance graphics card (the game page toggle or the Optimize Max check), it now changes only that one setting. Windows keeps other choices for the same program in the same place — for example Auto HDR — and those used to be replaced along with it. They are kept exactly as they were.
