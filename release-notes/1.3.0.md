## TrueStretch 1.3.0 — See which graphics chip VALORANT really used

### What's new
- **Optimize Max now checks which graphics chip VALORANT actually ran on.** Most gaming laptops have two: a weak one built into the processor (Intel or AMD) and the powerful gaming card (NVIDIA or AMD). Windows decides which one runs each game, and when it picks the weak one you lose a lot of FPS without any warning. VALORANT writes the chip it used into its own log every time it starts. TrueStretch now reads that and shows it under Windows, for example "Graphics chip VALORANT used: NVIDIA GeForce RTX 3060 Laptop GPU".
- If VALORANT ran on the built-in chip, the row tells you, and the "VALORANT on the fast graphics card" check above it fixes it from the next time the game starts. If the fast card is already chosen and the laptop still gave the game the weak chip, the row says that too.
- If VALORANT ran with no graphics driver at all (Windows' basic display driver, very low FPS), the row warns you.
- On PCs with only one graphics card there's nothing to check, so the row doesn't appear.

### Why it matters for the player
The "fast graphics card" setting asks Windows to use the gaming card. This new row shows whether VALORANT actually got it, using the game's own record. That's the difference between 60 and 200+ FPS on many laptops.

### Details
- Read-only: TrueStretch only reads VALORANT's log file. Nothing in the game is touched.
- Also checked for this release: VALORANT patch 13.10 (10 November) changes nothing that affects stretching.
