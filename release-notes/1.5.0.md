## TrueStretch 1.5.0 — Catches a switched-off page file before it crashes your game

### What's new
- **Optimize Max now checks the Windows page file.** The page file is extra room on your drive that Windows uses when memory (RAM) is full. Many "FPS boost" guides and tweak tools switch it off. That adds no FPS, and it means that the moment memory runs out — VALORANT plus a browser, Discord and a launcher is enough on many PCs — the game freezes or closes in the middle of a match.
- If the page file is switched off, the new row under Windows says so, and Apply lets Windows manage it again, which is how every PC is set up from the factory. It needs one administrator prompt and a restart.
- If your page file is on (managed by Windows or with a size you picked yourself), the row just shows it as fine. TrueStretch never changes a size you chose.

### Why it matters for the player
A closed game in the middle of a ranked match costs far more than a few FPS. This is one of the most common leftovers of old tweak guides, and it is hard to spot: nothing looks wrong until memory is full.

### Details
- Like every Optimize Max item, the change is checked after it is made, and Undo puts back exactly what was there before.
- The row also tells you when a change is waiting for a restart.
- Also checked for this release: VALORANT 13.10 — every game-log line TrueStretch relies on for stretching still looks the same.
