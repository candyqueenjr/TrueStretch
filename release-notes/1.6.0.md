## TrueStretch 1.6.0 — Now works on PCs with Smart App Control

### What's new
- **TrueStretch now runs on PCs where Windows blocked it.** Windows 11's *Smart App Control* blocks every program that isn't code-signed, and it has no "Run anyway" button, so on those PCs TrueStretch.exe simply wouldn't start. There is now a second way to install TrueStretch that works there: it runs TrueStretch from its open-source code with the official Python and Qt, and both of those are signed by their makers, so Smart App Control lets them run.
- **One command, then it's on your Desktop.** Open PowerShell (Start menu → type *PowerShell* → Enter) and paste:
  ```
  irm https://candyqueenjr.github.io/TrueStretch/install.ps1 | iex
  ```
  It installs Python for your Windows user if you don't have it, sets TrueStretch up, adds it to your Desktop and Start menu, and starts it. It doesn't change any Windows security setting.
- **That install updates itself, too.** When a new version comes out, *Update and restart* downloads it, checks it's the right version, and puts it in place when TrueStretch restarts. Your settings stay.
- **Star on GitHub.** Settings › Help and About have a *Star on GitHub* button. TrueStretch is free and open source, and stars help other players find it.

### Which one should I use?
- **TrueStretch.exe** (below), if it opens on your PC. Most PCs only show "Windows protected your PC" once → *More info* → *Run anyway*.
- **The one-command install**, if Windows says *"Smart App Control blocked an app that may be unsafe"*.

### Why it matters for the player
Nobody should have to switch off a Windows security feature to use a free tool. Until TrueStretch.exe itself is code-signed, this gets it running on every Windows 11 PC.
