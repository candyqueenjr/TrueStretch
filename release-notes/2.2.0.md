## TrueStretch 2.2.0 — Play never freezes the window, power settings work in every language, a faster app

A day spent on the engine room: the parts of TrueStretch that wait on Windows now wait in the background, the
Optimize Max power rows read Windows directly instead of reading its English text, and every page asks your
graphics driver once per refresh instead of dozens of times.

### What's new
- **Set in game** has its own filter on the Optimize Max page. The six settings only VALORANT's own menu can change
  were counted in the header but could only be found inside *To do* — now one click lists exactly those.
- **PLAY shows what it's waiting for.** When Play stretched has to turn the monitor drivers off (Windows asks for
  permission once), the button reads *Working…* and the badge next to it says *Turning monitor drivers off…* until
  it's done. Play then continues by itself.

### What's better
- **The window keeps working while Windows works.** Turning monitor drivers off or back on (from Play or from
  My PC) used to freeze the whole window for up to a minute — no redraw, no moving it, "Not responding" in the
  worst case. It now runs in the background; you can keep using the app meanwhile.
- **Optimize Max power rows on non-English Windows.** Processor minimum state, boost mode, core parking, USB
  selective suspend, PCI Express power saving and Wi-Fi power saving read their values straight from Windows'
  power API. Until now TrueStretch read the English text of `powercfg`, so on Portuguese, Spanish, Turkish,
  Russian (any non-English) Windows all six rows said *Not in this power plan* and could never be optimized.
  Apply, verify and undo go through the same API.
- **Faster and lighter.** Opening TrueStretch asked the graphics driver about your screens 33 times and listed
  the displays 21 times; every page refresh asked 5–9 times more. Each refresh now asks once and shares the
  answer across the whole page. On laptops with slow display drivers this is the difference between a window
  that appears at once and one that hangs for a few seconds.
- **A clear message instead of "error 259".** If an administrator command (pnputil, Optimize Max) is still
  running after its time limit, TrueStretch says so in words and tells you what to do, instead of reporting
  Windows' "still running" code as a failure.

### What's fixed
- One shared administrator runner for the monitor-driver switch and Optimize Max (there were two copies with
  slightly different error handling; the monitor one could report a wrong error code when the prompt failed).
- A leftover NVIDIA helper that nothing called is gone.
